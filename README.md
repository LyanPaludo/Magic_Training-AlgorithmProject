# MAGIC TRAINING

O jogo é baseado em C e allegro5, no momento não sei descrever bem como vai ser o jogo, criei uma base que seria como um space invaders com conjuração de magias, basicamente o usuário vai apertar uma sequência de botões e lançar magias para derrotar os inimigos bem no estilo space invades mesmo.

## Como Compilar e Rodar

Diga aqui quais ferramentas a pessoa precisa (ex: GCC, biblioteca do Allegro 5 instalada) e o comando para compilar.

## Como Jogar

* **A, D:** Movimentação Lateral
* **Sequência específica de teclas** Ataca / Lança feitiço
